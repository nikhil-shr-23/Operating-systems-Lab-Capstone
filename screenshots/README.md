# Screenshots

The `0*.png` files here were rendered by `docs/make_screenshots.py` from the **real captured output**
of the commands below (drawn onto a terminal-style canvas). They are not live terminal captures.

For your submission, please run these 6 commands yourself from the `osrm/` folder in Terminal and take
your own screenshots. The banner prints your name, roll number and section, so make sure it is visible
(scroll up to the banner for the long outputs).

1. `./run.sh test`
2. `python3 main.py sched --algo rr`
3. `python3 main.py memory --belady --no-trace`
4. `python3 main.py deadlock`
5. `python3 main.py storage --disk-only`
6. `./run.sh demo`
